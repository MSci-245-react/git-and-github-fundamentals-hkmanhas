In Lecture 1, JavaScript Foundations, I learned the difference between `const` and `let`, 
in what situations they should be used, and how this differs from Python code.

- `const` is for a variable that should not be reassigned and is the default
- `let` is for variables that should be assigned (e.g. counters, undefined parameters)

```javascript
const x=5;
const y=3;
console.log(x+y);
```
